FLINS — Master Architecture & State Snapshot

1. Загальна інформація
Назва проєкту: Flins
Автор та розробник: dreamyr
Призначення: Преміальний нативний простір для особистого щоденника та бази нотаток у стилі Notion із глибокою естетикою паперового записника, повною автономністю, локальним сховищем та інтегрованим персональним ШІ-бібліотекарем.
Платформа: Нативний застосунок для macOS на базі Tauri 2.0 (архітектурно на 100% готовий до збірки під Windows, Linux, iOS та Android).
Технологічний стек:
Бекенд: Rust (Tauri 2.0 Core, rusqlite bundled, Cocoa AppKit FFI).
Фронтенд: React 18/19, TypeScript, Vite.
Стилізація: Tailwind CSS 3.4 з кастомними палітрами cozy та night.
Текстовий рушій: BlockNote 0.22 (TipTap / ProseMirror).
База даних: Вбудована локальна SQLite (flins.db у системній папці ~/Library/Application Support/FlinsData/).
Аудіо-рушій: Нативний Web Audio API (синтез кришталевих та дерев'яних звуків з автоматичним перепідключенням частоти для AirPods через подію devicechange).
2. Фірмовий стиль та теми

2.1. Логотип
Фірмовий знак: Авторська каліграфічна монограма «F».
Для macOS Dock: Повнотілі squircle-іконки з фоном (src/assets/logo-dark.png та src/assets/logo-light.png).
Для інтерфейсу сайдбара: Прозорі монограми (logo-dark-transparent.png та logo-light-transparent.png).

2.3. Системна інтеграція
3 режими оформлення: system (автоматично за графіком macOS), light (примусово світанок), dark (примусово ніч).
Динамічний Dock: При зміні теми застосунок через Rust-команду set_dock_icon миттєво оновлює іконку прямо в системній панелі Dock macOS.
Іконка теми: Системний чистий вектор Monitor із Lucide (без дешевих емодзі).

4. Повний стан реалізованого функціоналу

4.1. Редактор та фізика письма
Блоковий рушій BlockNote: Створено без перевантаженого словника, загорнуто в ErrorBoundary — нуль вилетів у чорний екран при русі мишкою.
SideMenuController (+ та 6 точок ::): Повернуто нативний контролер бічного меню BlockNote для створення нових блоків і перетягування рядків безпосередньо в полі тексту.
Word-like Click & Type: 1 клік у порожнечу — курсор на початок нового рядка; 2 кліки — позиціонування в точні координати з нерозривними пробілами \u00A0.
Перенесення тексту на інший аркуш ([ 📄↗ ]): Кнопка в тулбарі відкриває динамічний поповер, який акуратно прив'язується до координат виділеного тексту без затемнення всього робочого простору. Повне очищення виділеного тексту з поточної сторінки через TipTap deleteSelection() з негайним збереженням у SQLite.
Швидкий рерайт ✦: Компактна переливна зірочка (24px) у плаваючому тулбарі для відправки тексту у Flins AI з повною двомовною локалізацією підказок.
Локалізований вибір шрифтів: Селектор шрифтів динамічно перекладає назви стилів (Lora, Caveat, Mono, Sans) відповідно до поточної мови застосунку (UK / EN).
Вставка часу: Кнопка + Час (+ Time) вставляє мітку часу строго в поточну позицію друку курсора.
4.2. Паперовий щоденник та естетика
Каліграфічна шапка: Великий номер дня, рукописний день тижня (Caveat), коректно розташована Washi Tape.
Фіксація Washi Tape: Стрічка скотчу закріплена строго по центру верхнього краю паперового аркуша (absolute -top-3 left-1/2 -translate-x-1/2), що усуває налізання на дату або сповзання всередину аркуша при зміні відступів.
Адаптивність при відкритому AI: Стікер настрою та оцінка дня автоматично шикуються вертикально (настрій зверху, оцінка знизу строго по центру), ніколи не перекриваючись і не зрізаючись.
Кастомізація символів оцінки: Повністю відновлено динамічне відображення символу в шапці щоденника на основі конфігурації aesthetics.ratingSymbol (☕ Кава, ⭐ Зірочки, ❤️ Сердечка, 🌿 Паростки, 🕯️ Свічки, ✨ Іскри).
Підвал аркуша:
Ліворуч: назва документа / дата.
По центру: велика зірка ✦ (37px). Центрування вирівняно точно по пунктирній межі аркуша (клік строго по центру гліфа). Під час генерації перетворюється на сяючий лоадер.
Праворуч: номер аркуша (Sheet 1 / Аркуш 1).
Нижче під усім: «Тиха порада бібліотекаря» строго по центру з відступом і лімітом у 130 символів.
4.3. Календарна система
Адаптивна кнопка дати: Динамічний текст автоматично підлаштовується під доступну ширину (наприклад, 3 лист. 2026 на стандартному екрані та компактне 03.11.26 при звуженні чи відкритому AI). Кнопка ізольована через min-w-0 overflow-hidden, що виключає налізання тексту на кнопки аркушів.
Захист від зрізання поповера: Шапка має overflow-visible relative z-30, завдяки чому вікно випадаючого календаря ніколи не обрізається краями блоків.
Фільтри позначок: Компактні векторні іконки без зайвого тексту (Smile, SunMedium, Star, CircleDot) у міні-календарі та річному огляді на 12 місяців.
Контейнеризація дат: Порожні дні не створюють записів на диску до першого реального введення.
4.4. Горизонтальний скрол-контейнер аркушів
Скрол-стрічка сторінок: Кнопки номерів аркушів [ 1 ] [ 2 ] [ 3 ]... розміщені в еластичному контейнері з плавним горизонтальним скролом (коліщатком миші або трекпадом) без візуального сміття скролбарів.
Автоцентрування: При перемиканні аркушів активна кнопка автоматично доскролюється в поле зору (scrollIntoView({ inline: 'nearest' })).
Закріплена кнопка +: Кнопка додавання нового аркуша та іконка зірочки закріплені поруч зі стрічкою і завжди доступні для швидкого кліку.
4.5. Файлове дерево нотаток (NotesManager.tsx)
Плавне згортання без розриву DOM: Сайдбар нотаток не демонтується при згортанні, а плавно змінює ширину від 34px до заданої через CSS-перехід transition-[width] duration-300.
Виправлено вертикальний напис: Текст «НОТАТКИ ТА ПАПКИ» у згорнутому стані має безпечний верхній відступ (mt-20) і більше ніколи не перекриває стрілочку розгортання.
Усунено передчасне обрізання назв нотаток: Кнопки редагування та видалення тепер спливають абсолютно над краєм елемента лише при наведенні курсора, звільняючи назві нотатки повну ширину рядка.
4.6. Гібридне збереження (SQLite + Finder Vault)
SQLite Core: Моментальне автозбереження у фоні за принципом Debounce (400 мс після зупинки вводу). Холодний старт миттєво відновлює текст без перемикання сторінок.
Пам'ять останніх днів у SQLite (load_recent_journal_entries): Нативний Rust-метод витягує дату, настрій, погоду, оцінку та очищений текст попередніх днів (з виключенням порожніх сторінок) для формування контексту ШІ.
Фізичне сховище: Опціональне дзеркалювання у звичайні .md файли з YAML Frontmatter у Finder за людинозрозумілою ієрархією папок.
Вибір папки через Finder: Нативна Rust-команда pick_vault_folder через AppleScript відкриває офіційний провідник macOS.
Статус збереження: Нейтральна іконка ліворуч від підрахунку слів із делікатним спливаючим тултіпом • Запис збережено / Збереження....
4.7. Аудіо-система Flins
5 стилів звуку: Тепла калімба (дерево), Затишна арфа (щипок), Вінтажна друкарка (клік), Тихий дзен-дзвін, Кришталева челеста, Без звуку.
Знижена гучність: Рівень звуку оптимізовано під тиху комфортну роботу (~0.07).
Слухач devicechange: Звук автоматично перепідключається при переході на AirPods / Bluetooth-навушники.
4.8. Flins AI: Повний потоковий рушій та персональний бібліотекар
Автопошук та підключення сервера в 1 клік (detectLocalServer):
Автоматичне опитування ендпоінтів LM Studio (OpenAI-compatible /v1/models, нативний /api/v1/models) та Ollama (/api/tags).
Автоматичне зчитування назви завантаженої моделі (Qwen, Llama, Gemma тощо).
Зелений статус-бейдж підключення у Налаштуваннях з індикатором протоколу.
Надійний парсер getBaseOrigin на базі new URL().origin, що виключає появу дубльованих шляхів виду /api/v1/chat/v1/chat/completions.
SSE Streaming Pipeline: Живе посимвольне виведення токенів у реальному часі через ReadableStream з підтримкою моментального переривання генерації кнопкою ■ (Зупинити) або закриттям шторки (AbortController).
Відокремлення Reasoning (ходу думок):
Для моделей із мисленням (Qwen Distill, DeepSeek-R1) внутрішній монолог на льоту відокремлюється від чистої відповіді.
Роздуми ховаються в елегантний розгортаний спойлер 💭 Хід думок бібліотекаря, не засмічуючи чат.
Усунено баг перезапису: роздуми більше ніколи не копіюються в основний текст повідомлення.
Бронебійний анти-JSON екстрактор (extractCleanResponseText):
Автоматичне знешкодження помилкових викликів функцій (Tool Calling) у Llama 3.1.
Якщо модель видає {"name": "...", "parameters": {"s": "..."}}, рушій на льоту дістає чистий текст незалежно від назви параметра (s, text, content, val).
Фільтрація випадкових китайських ієрогліфів (/[\u4e00-\u9fff]/g) та префіксів Revised Draft:.
Мікро-слід пам'яті (Memory Injection + Guardrail):
Автоматичне підтягування очищеного контексту останніх 1–2 днів з SQLite перед запитом.
Залізний Guardrail: ШІ заборонено згадувати минулі події, якщо користувач не посилається на них сам («як вчора», «пам'ятаєш»).
Тумблер у шторці: [✓] Пам'ятати події попередніх днів для миттєвого вимкнення пам'яті за бажанням.
Розділення персони автора та ШІ: У системному промпті чітко розмежовано метадані автора та безтілесну роль бібліотекаря — ШІ більше ніколи не приписує собі настрій 🕯️ чи погоду ☀️.
Вільне копіювання тексту: З чату прибрано select-none, активовано повноцінне виділення мишкою та копіювання (select-text cursor-text).
Плавний ресайз шторки: Під час перетягування межі шторки CSS-анімації вимикаються (transition-none), усуваючи ривки та розсинхрон рендерингу тексту.
4.9. Оживлення всіх 5 інтелектуальних точок застосунку
«Перо» у чаті: Вільний діалог та художнє перетворення сирих думок автора у 4 тонах (Затишний, Філософський, Лаконічний, З гумором) від першої особи (Я) без обмежень на кількість речень.
«Швидкий рерайт» (✦ у тулбарі та Cmd + J): Пряме літературне полірування, скорочення або виправлення граматики виділеного тексту без витоку роздумів на аркуш.
«Тиха порада на полях» (велика зірка ✦ 37px): Клік по зірці аналізує реальний текст аркуша за вибрану дату й генерує живу лаконічну філософську цитату через локальну модель.
«Щоденне питання» (Daily Prompt у шапці): Кнопка оновлення генерує унікальне авторське запитання для вечірньої рефлексії через підключену модель.
Вкладка «Хроніка»: Створення реальних конспектів за текстом поточної нотатки/аркуша, тижневого огляду та місячного літопису за структурованими рубриками (✦ Головна думка, 📅 Події, 🕯️ Атмосфера, 🌱 Висновок).
4.10. Орбітальний лоадер Flins AI (AiSparkleLoader.tsx)
Атмосферний індикатор очікування: Замість трьох точок реалізовано велику сяючу неонову ауру з подвійним блюром (blur-xl + blur-md) та двома супутниками, що кружляють по еліптичних орбітах у протилежні боки.
Єдиний візуальний стиль: Використовується в чаті під час очікування відповіді, на місці великої зірки ✦ 37px під час генерації поради та поруч із щоденним питанням.
Інтерактивна підказка: При наведенні плавно спливає делікатний тултіп «Обробка запиту, зачекайте...» (UK / EN).
